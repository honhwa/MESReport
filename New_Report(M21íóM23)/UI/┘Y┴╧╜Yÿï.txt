對開發人員來説，需要關注的一般只有src以下的文件
├─.gitlab                   Gitlab的暫存檔
│  ├─issue_templates
│  └─merge_request_templates
│
├─.vs                       VScode的暫存檔
│
├─public
│
└─src
   │  App.vue               路由總出口
   │  main.js               入口文件,將vue挂載在一個id為app的實際的html節點
   │
   ├─api                    用來定義call api的方法，by報表定義，進行請求攔截
   │  └─daylimove
   │          index.js
   │
   ├─assets                 用來存放靜態資源,如css,image等
   │  ├─css
   │  ├─img
   │  └─styles
   │
   ├─components             components文件夾是組件定義的地方
   │  ├─basic               共用組件
   │  │  ├─form             共用組件-表單
   │  │  │      baseModel.vue
   │  │  │
   │  │  └─table            共用組件-表格
   │  │          NormalTable.vue
   │  │
   │  ├─Error               共用組件-錯誤頁
   │  │      403.vue
   │  │      404.vue
   │  │
   │  ├─Form                一些公用組件
   │  │      MergeTable.vue
   │  │      MergeTest.vue
   │  │      Other.vue
   │  │      UploadExcel.vue
   │  │      UploadExcelTest.vue
   │  │
   │  ├─Layout
   │  │  │  bus.js          中央事件總綫-用於組件閒信息傳遞
   │  │  │  Header.vue

   │  │  │  localstorage.js
   │  │  │  Logo.vue
   │  │  │  Sidebar.vue

   │  │  └─up-excel

   │  └─el-table
   │          adaptive.js
   │          index.js
   │
   ├─hooks                   組件公用方法

   │  └─OperationPerformance
